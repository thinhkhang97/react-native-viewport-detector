# react-native-viewport-detector v2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.0: a web-compatible `useInView` / `<InView>` / `<ViewportProvider>` API on an event-driven JS engine with zero idle cost and nested-root clipping, while v1 exports keep their 1.0.8 polling behaviour.

**Architecture:** Pure geometry and threshold modules feed a `JsEventEngine` that owns a tree of roots and a set of targets, re-measures only after invalidations (scroll, layout, app state, dimensions), coalesced to one pass per animation frame, and notifies targets only on threshold crossings. React bindings (`ViewportProvider`, `useViewportRoot`, `useInView`, `InView`) talk to the engine through context; v1 components live in `src/compat` on their own polling scheduler but share the geometry module.

**Tech Stack:** TypeScript 5.6, React ≥ 18, React Native ≥ 0.72, Jest 29 + `@testing-library/react-native` 13 (RN jest preset), `react-native-builder-bob`, Expo SDK 58 example app, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-04-v2-design.md`

## Global Constraints

- Peer deps exactly: `"react": ">=18"`, `"react-native": ">=0.72"`; zero runtime `dependencies`.
- Core entry < 6 kB min+gz (checked in Task 13).
- Package name stays `react-native-viewport-detector`; entry points `.`, `./jest`; `./reanimated` NOT published in v2.0.
- No timers or per-frame work while idle in the new API (only exception: v1 exports, §4.4 of the spec).
- Re-render a component only when `inView` changes, or `entry` changes and the component read it.
- Wrappers rendered by the library set `collapsable={false}`.
- Dev-only warnings are `console.warn`, once per message, inside `if (__DEV__)`.
- Public option names exactly: `threshold`, `rootMargin`, `triggerOnce`, `skip`, `initialInView`, `delay`, `onChange`; provider props `rootMargin`, `pauseWhenInactive` (default `true`), `engine` (`'auto' | 'js'`, default `'auto'`).
- `master` is protected; all work lands via one PR from `feat/v2` with CI green.
- **Commit cadence (owner preference):** do not commit per task. Skip every "Checkpoint" commit until the owner has manually verified the finished branch on device (Task 12), then commit as the owner chooses.
- Files: source ≤ 500 lines, components ≤ 800; functions < 50 lines; no mutation of inputs (return new objects).

## Review Focus

1. **List recycling / fast unmount** (FlatList, FlashList cells mounting and unmounting mid-scroll): no callbacks after unmount, no leaked registrations, no pending measurement resolving into a dead target. → Task 6 test `drops targets unobserved during an in-flight async pass`; Task 8 test `does not call onChange after unmount`.
2. **User handlers on the scroll child**, including an `Animated.event` object as `onScroll`: composed, never replaced; native-driver objects detected. → Task 7 tests `calls the child's own onScroll and onLayout` and `warns once and stays functional with a native-driver Animated.event`.
3. **Zero-size or not-yet-laid-out targets** (`display: 'none'`, height 0, collapsed views): never `NaN`, reported as not intersecting. → Task 2 test `intersectionRatio is 0 for a zero-area target`; Task 6 test `zero-size target reports not intersecting`.
4. **Rotation / window resize / roots that move** (keyboard, header collapse): re-measured on `Dimensions` change and on `invalidate()`. → Task 7 test `re-measures on Dimensions change`.
5. **Options recreated every render** (inline `threshold={[0, 0.5]}`, `rootMargin={{ bottom: 100 }}`): no re-registration loop, no extra renders. → Task 8 test `inline option objects do not re-observe`.

### Task 2: Geometry module

**Interfaces:**
- Produces (all pure, return new objects):

### Task 6: JsEventEngine

**Files:** Create `src/engine/types.ts`, `src/engine/jsEventEngine.ts`, `src/__tests__/engine/jsEventEngine.test.ts`.

**Interfaces:**
- Consumes: Tasks 2–5.
- Produces:
  ```ts
  type InvalidateReason = 'scroll' | 'layout' | 'content-size' | 'app-state' | 'dimensions' | 'mount' | 'options' | 'manual';
  interface NormalizedOptions { thresholds: number[]; targetMargin: Margin }
  interface RootHandle { readonly id: number; readonly parent: RootHandle | null }
  interface EngineStats { passes: number; measurements: number; notifications: number }
  interface Engine {
    registerRoot(parent: RootHandle | null, getNode: () => HostNode | null, margin: Margin): RootHandle;
    updateRootMargin(root: RootHandle, margin: Margin): void;
    unregisterRoot(root: RootHandle): void;
    observe(getNode: () => HostNode | null, root: RootHandle | null, opts: NormalizedOptions,
            cb: (entry: ViewportEntry) => void): () => void;
    invalidate(reason: InvalidateReason, root?: RootHandle): void;   // root omitted = everything
    setPaused(paused: boolean): void;
    getStats(): EngineStats;
  }
  function createJsEventEngine(deps?: { getWindowRect?: () => Rect; now?: () => number;
                                        measure?: (n: HostNode) => Rect | Promise<Rect> }): Engine & { dispose(): void };
  // src/engine/stats.ts — every engine registers on create, unregisters on dispose
  function __getAllStats(): EngineStats;   // summed over live engines; used by the example Benchmark only
  ```
- Behaviour: `invalidate` marks the root subtree dirty and requests a frame. A pass measures dirty roots top-down (`outermostRootRect` / `nestedRootRect`), then their targets, builds entries with `computeEntry`, and calls `cb` only when `bucketOf` changed (first measurement always notifies). Sync measurements complete in the same frame; if any measurement is async, the pass awaits all (`Promise.all`) and drops results for targets/roots unobserved meanwhile. `setPaused(true)` notifies every target with a not-intersecting entry (bucket `-1`) and ignores invalidations; `setPaused(false)` invalidates everything. Notifications within one pass are wrapped in `unstable_batchedUpdates` from `react-native`.

- [ ] **Step 1: Failing tests** with an injected `measure` that reads rects from a mutable map keyed by node id and `getWindowRect` returning `{0,0,390,844}`:
  - first pass notifies each target once; second `invalidate('scroll')` with unchanged rects → no notification, `getStats().passes` incremented;
  - three `invalidate` calls before a frame → one pass;
  - no invalidation → no pass and `jest.getTimerCount() === 0` (idle is free);
  - nested root clipping: inner root below the outer root → target not intersecting; move both into view → intersecting;
  - thresholds `[0, 0.5]` notify at 0→0.3 (bucket 0) and 0.3→0.6 (bucket 1), not at 0.6→0.7;
  - **`zero-size target reports not intersecting`**;
  - **`drops targets unobserved during an in-flight async pass`** (measure returns Promises; unobserve before resolve → cb never called);
  - `setPaused(true)` → every in-view target gets `isIntersecting: false`; `setPaused(false)` → re-measured and notified back;
  - invalidating one root does not measure targets of a sibling root (`getStats().measurements`).

### Task 8: useInView and InView

**Files:** Create `src/react/useInView.ts`, `src/react/InView.tsx`, tests `src/__tests__/react/useInView.test.tsx`, `src/__tests__/react/InView.test.tsx`; Modify `src/index.ts`, `src/types.ts`.

- Produces (types exactly as spec §4.2):

- Behaviour:
  - Observation is keyed by `thresholdsKey`, margin values, `skip`, and the root — not by object identity. `onChange` is read from a ref (latest wins).

  - `skip`: unobserve, keep last state; un-skip re-observes and re-measures.
  - No context root and `root !== null` → `warnOnce('no-root', 'useInView: no <ViewportProvider> found — scrolling will not be tracked. Wrap your scroll view in <ViewportProvider> or pass root={null} for static screens.')` and use `getDefaultEngine()`.
  - Entry state updates only on bucket changes (the engine guarantees this), so no extra renders.
  - Attaching the ref (non-null node) calls `engine.invalidate('mount', root)`; `InView` also composes its host `onLayout` with `invalidate('layout', root)`.
